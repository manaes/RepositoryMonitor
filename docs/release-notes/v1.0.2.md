## RepositoryMonitor v1.0.2

시작 시 폴더 접근 권한이 없으면 빈 리스트로 남던 문제를 복구하도록 개선.

### 버그 수정
- 시작 시 macOS 폴더 접근 권한(TCC)이 거부/대기 상태여서 저장소 발견이 0건이면, 권한 허용 후에도 앱 재시작 전까지 빈 리스트로 남던 문제 수정 — 목록이 비어 있으면 폴링 주기마다 discovery를 재시도한다.

### 기능 개선
- 릴리즈 노트를 `docs/release-notes/<tag>.md` 파일로 관리 (AIAgentMonitor와 동일한 정책).

### 알려진 문제 안내
- 업데이트 후 목록이 비어 보이면 macOS 폴더 접근 권한(TCC)이 조용히 거부된 상태일 수 있습니다. **설정에서 루트 폴더를 다시 선택**하거나, 시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더에서 RepositoryMonitor의 데스크탑 폴더 권한을 껐다 켜면 복구됩니다.

### 검증
- `cargo test` 57개 + `vitest` 24개 통과.

### 설치
| 플랫폼 | 파일 |
|---|---|
| macOS Apple Silicon | `*_aarch64.dmg` |
| macOS Intel | `*_x64.dmg` |
| Windows | `*_x64_en-US.msi` 또는 `*_x64-setup.exe` |

> macOS 빌드는 Apple Developer ID로 서명·공증되어 별도 Gatekeeper 우회 없이 바로 실행됩니다.
